# 🚀 Comandos para Iniciar el Proyecto

## En PowerShell:

```powershell
# 1. Ir al directorio del proyecto
cd C:\Users\Random\Downloads\uploaded_files

# 2. Iniciar la aplicación
py -3.12 app.py
```

## Listo! 🎉

La aplicación se abrirá en: http://127.0.0.1:7860

---

## Si necesitás instalar dependencias primero:

```powershell
# Instalar todas las dependencias
pip install -r requirements.txt
```

## Si hay errores:

```powershell
# Verificar que Python 3.12 esté instalado
py -3.12 --version

# Si no funciona, probar con:
python app.py
```
