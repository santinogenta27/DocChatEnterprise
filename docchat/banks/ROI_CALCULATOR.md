# 💰 ROI Calculator - Modo BANKS

## 📊 Cálculo de ROI para Bancos

### Fórmula Base

```
ROI = (Ahorro Total - Costo BANKS) / Costo BANKS × 100
```

### Componentes del Ahorro

#### 1. Reducción de Tiempo Manual
```
Tiempo Manual = Entidades × Tiempo por Entidad
Tiempo Automatizado = Tiempo Manual × 0.3 (70% reducción)
Ahorro de Tiempo = Tiempo Manual - Tiempo Automatizado
```

#### 2. Reducción de Costos Operativos
```
Costo Manual = Tiempo Manual × Tarifa Analista
Costo Automatizado = Tiempo Automatizado × Tarifa Analista
Ahorro de Costos = Costo Manual - Costo Automatizado
```

#### 3. Reducción de Falsos Positivos
```
Falsos Positivos Manuales = Total Alertas × 0.95 (95% falsos)
Falsos Positivos BANKS = Total Alertas × 0.05 (5% falsos)
Ahorro en Revisión = (Falsos Manuales - Falsos BANKS) × Tiempo Revisión × Tarifa
```

#### 4. Prevención de Multas
```
Riesgo de Multa = Probabilidad × Monto Potencial
Reducción de Riesgo = Riesgo × 0.8 (80% reducción con BANKS)
Ahorro en Multas = Reducción de Riesgo
```

## 📈 Ejemplo de Cálculo

### Escenario: Banco Mediano
- **Entidades procesadas/mes:** 1,000
- **Tiempo manual por entidad:** 15 minutos
- **Tarifa analista:** $50/hora
- **Alertas/mes:** 200
- **Tiempo revisión falsos positivos:** 30 min/alert
- **Riesgo multa anual:** $500,000
- **Pricing BANKS:** Tier 2 ($14,999/mes)

### Cálculo:

#### Ahorro de Tiempo
```
Tiempo Manual = 1,000 × 15 min = 15,000 min = 250 horas
Tiempo Automatizado = 250 × 0.3 = 75 horas
Ahorro de Tiempo = 250 - 75 = 175 horas/mes
```

#### Ahorro de Costos Operativos
```
Costo Manual = 250 × $50 = $12,500/mes
Costo Automatizado = 75 × $50 = $3,750/mes
Ahorro Operativo = $12,500 - $3,750 = $8,750/mes
```

#### Ahorro en Falsos Positivos
```
Falsos Manuales = 200 × 0.95 = 190
Falsos BANKS = 200 × 0.05 = 10
Reducción Falsos = 190 - 10 = 180
Ahorro Falsos = 180 × 0.5h × $50 = $4,500/mes
```

#### Ahorro en Multas
```
Riesgo Multa Mensual = $500,000 / 12 = $41,667
Reducción Riesgo = $41,667 × 0.8 = $33,333/mes
```

#### Total Ahorro Mensual
```
Ahorro Total = $8,750 + $4,500 + $33,333 = $46,583/mes
```

#### ROI
```
Costo BANKS = $14,999/mes
ROI Mensual = ($46,583 - $14,999) / $14,999 × 100 = 210%
ROI Anual = 2,520%
```

#### Payback Period
```
Payback = $14,999 / $46,583 = 0.32 meses = ~10 días
```
