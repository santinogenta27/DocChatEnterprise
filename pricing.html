Preguntas Frecuentes

Todo lo que necesitas saber antes de comprar

¿Qué significa "On-Premise"?
Significa que recibes el código fuente completo y lo instalas en TUS propios servidores. Tus datos nunca salen de tu infraestructura. Tienes control total sobre el sistema.
¿Es un pago único o mensual?
Es un pago único. Compras la licencia una vez y el software es tuyo para siempre. No hay costos mensuales ni renovaciones obligatorias.
¿Qué necesito para instalarlo?
Un servidor con Python 3.10+, 8GB RAM mínimo (16GB recomendado), y conexión a internet para las APIs de IA. Funciona en Windows, Linux y Mac. Incluimos documentación detallada de instalación.
¿Necesito API keys de OpenAI/Anthropic?
Sí, necesitas tu propia API key de OpenAI o Anthropic. Esto significa que pagas directamente a ellos por uso, manteniendo costos bajos y control total sobre tus datos.
¿Puedo modificar el código?
¡Absolutamente! Recibes el código fuente completo. Puedes modificarlo, personalizarlo y adaptarlo a tus necesidades. Con la licencia Unlimited, incluso puedes revenderlo como white-label.
¿Cómo funciona el soporte?
Professional incluye 6 meses de soporte por email. Enterprise incluye 1 año de soporte prioritario con respuesta en 24h. Unlimited incluye soporte de por vida con acceso directo.
